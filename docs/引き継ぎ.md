## デザインと内容の方針

朱色・生成りと実際の活動写真を使う。見出しを揃え、上下の余白を増やしすぎない。人物コラージュは均等な列にしなくてもよいが、人物同士・文字には重ねない。スマートフォンも必ず確認する。

Aboutの中央メッセージは「稼げ、学べ、交れ。」。人物の一部は利用者の指示により顔を加工した画像。未加工の本人写真と誤って説明しない。

上部の参加ボタンはメールアプリを直接開かず `#contact` へスクロール。Next Moaiの問い合わせは `#join` へ。メールアドレスはJoin us内に掲載。

信用保証協会の法人名を協賛枠に出すことは取りやめ済み。支援制度へのリンクは別用途で残している。

## 作業手順

1. `git status` と現在のブランチを確認。無関係な作業ファイルは保護する。
2. 最新のmainを基に `codex/` で始まる作業ブランチを作る。
3. 指定範囲を修正。新しいライブラリは原則不要。
4. `node --check site/dist/app.js`、`git diff --check` を確認。ブラウザーで写真表示・写真切替・リンク・スマートフォンのはみ出しと人物の重なりを確認。
5. Pull Requestを作り、修正と確認結果を説明する。公開が明示されていなければ統合せず結果を見せる。
6. 公開が承認されたら統合し、Actions成功と公開URLを確認する。

原写真・個人情報・認証情報・試作は不用意にコミットしない。サイト上で必要な最終素材だけを追加する。
